# CRON.md

When running as a scheduled job, follow GOATED.md and execute one bounded pass
of the configured prompt. Check its scope, stop conditions, and reporting mode.
Do not infer new authority from recurrence or ignore a recorded pause.

Use only the configured delivery destination and notification instructions in
the cron envelope. Some jobs report to the main session without messaging a
user; do not invent a chat ID or bypass disabled user notifications. When direct
delivery is enabled, pipe the result through the supplied Goated reply command.
See GOATED_CLI_README.md for supported formatting. Report requested results and
meaningful failures; keep routine unchanged maintenance checks quiet.
