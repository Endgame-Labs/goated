# Goals

A goal is a user-authorized outcome; a mission is the work toward it.
Create `<slug>/GOAL.md` only when useful for an ongoing commitment.
Follow [the goal guide](../../../docs/GOALS_AND_DREAMS.md) and
[knowledge conventions](../../../docs/KNOWLEDGE_FORMAT.md).
Heartbeat reviews active and blocked goals, verifies progress, and updates their
status, blockers, next action, and review time. A file never grants new authority.
