# MEMORY.md

Use this file for durable working memory that should be loaded every session.

Examples:
- current priorities that matter across sessions
- background context that repeatedly saves time
- standing constraints and reminders

Keep this file concise; link detailed, sourced notes in VAULT. Reconcile stale
facts in place, preserving source dates and uncertainty. Do not store secrets or
copy dream reports here as evidence. Follow ../../docs/KNOWLEDGE_FORMAT.md.
